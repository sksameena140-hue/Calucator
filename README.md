# 🧮 Python Desktop Calculator

A simple desktop calculator built using Python and Tkinter. This project provides a graphical user interface for performing basic arithmetic calculations.

## ✨ Features

* Addition, subtraction, multiplication, and division
* Decimal number support
* Interactive calculator buttons
* Clear and delete functionality
* Keyboard input support
* Error handling for invalid calculations and division by zero
* User-friendly desktop interface

## 🛠️ Technologies Used

* Python 3
* Tkinter
* Python AST module
* Visual Studio Code

## 🚀 How to Run

### 1. Install Python

Download Python from https://www.python.org/downloads/

### 2. Download or clone this repository

```bash
git clone https://github.com/YOUR-USERNAME/python-desktop-calculator.git
```

### 3. Open the project folder

```bash
cd python-desktop-calculator
```

### 4. Run the calculator

```bash
python calculator.py
```

On Windows, you can also use:

```bash
py calculator.py
```
